# Known issues

- **Freezer room:** the ice flickers and shows spikes across the room.
- **Frame rate:** busy rooms, such as the kitchen and the fire imp fights, can drop below 60 fps. The game still runs at the right speed.
- **Death effect:** a box can show around the death effect.
- **Quit prompt:** the Yes/No text may be missing.
- **First load:** start-up can occasionally hang on the first loading screen. Close the game and start it again.
