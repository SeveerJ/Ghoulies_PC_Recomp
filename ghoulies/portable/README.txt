Grabbed by the Ghoulies - PC port (test build)

To play: double-click "Play.bat" (or ghoulies_recomp.exe).
  - Play with an Xbox / XInput controller plugged in.
  - F1: settings menu. Alt+Enter: fullscreen. F11: save a frame capture (for bug reports).
  - Settings are in settings.ini. If the laptop struggles, set Resolution = 480.

Needs: 64-bit Windows 10 or 11 and a DirectX 11 graphics card (any recent laptop).
The whole folder runs from the USB stick; saves go in game_files\UDATA on the stick.

If it crashes: play_log.txt in this folder records why.
